# GUI 组件优化计划

## 当前状态总结

2. ✅ 车辆状态颜色渲染系统

## GUI 组件现状分析

### 1. Toolbar（工具栏）- 需要优化 ⚠️

**当前组件：**

- 播放/暂停按钮
- 时间显示（仿真时间+实时时间）
- 速度倍率滑块（0.1x-15x）
- 重置视图按钮

**存在问题：**

- 时间显示格式可优化（当前显示两个时间，用户可能只关心仿真时间）
- 速度倍率滑块的数值显示不够直观
- 按钮布局较紧凑，不够美观
- 缺少仿真状态指示（运行中/暂停/错误等）

**优化建议：**

- [ ] 简化时间显示：仅显示仿真时间，格式为"时:分:秒.毫秒"
- [ ] 改进速度控件：显示"x1.0"格式，添加常用速度快捷按钮(x0.5, x1.0, x2.0, x5.0)
- [ ] 优化按钮间距和视觉效果
- [ ] 添加仿真状态 LED 指示灯（绿色运行/红色暂停/黄色错误）

### 2. StatusPanel（状态面板）- 布局需优化 ⚠️

**当前组件：**

- 全局状态区（仿真时间、车辆数量、已完成任务数）
- ObjectInspector（对象检视器）
- TaskListView（任务列表视图）

**存在问题：**

- 三个区域比例分配不够合理（35%对象检视器+剩余任务列表）
- 全局状态信息过于简单，缺少重要运营指标
- 区域间的分隔线视觉效果较弱
- 缺少系统性能指标显示

**优化建议：**

- [ ] 重新分配比例：25%全局状态 + 35%对象检视器 + 40%任务列表
- [ ] 扩充全局状态信息：
  - 系统效率指标（任务完成率、平均等待时间）
  - 车辆状态统计（空闲/繁忙/故障数量）
  - 仓库利用率统计
- [ ] 增强分隔线：使用阴影效果和更明显的颜色
- [ ] 添加性能监控（FPS、内存使用率）

### 3. ObjectInspector（对象检视器）- 信息展示需丰富 ⚠️

**当前功能：**

- 显示选中对象的基本属性（ID、类型、状态）

**存在问题：**

- 信息显示过于基础，缺少实用的运营数据
- 缺少历史状态跟踪
- 没有操作快捷方式
- 文本排版可以更美观

**优化建议：**

- [ ] 丰富车辆信息显示：
  - 当前任务详情（起点 → 终点、货物类型、优先级）
  - 历史任务统计（今日完成数、总行驶距离）
  - 实时状态（速度、电量、载货状态）
- [ ] 丰富设备信息显示：
  - 库存状态（当前货物类型、数量、容量利用率）
  - 操作历史（最近存取记录、高峰时段统计）
  - 设备状态（在线时长、故障历史）
- [ ] 添加快捷操作按钮（如：查看历史轨迹、暂停该车辆等）

### 4. TaskListView（任务列表视图）- 交互性需增强 ⚠️

**当前功能：**

- 显示待处理任务列表
- 支持滚轮滚动

**存在问题：**

- 任务信息显示格式不够直观
- 缺少任务优先级和状态的视觉区分
- 没有搜索和过滤功能
- 不支持任务操作（取消、修改优先级等）

**优化建议：**

- [ ] 优化任务显示格式：
  - 使用图标区分任务类型（入库/出库/移库）
  - 颜色编码显示优先级（红色高/黄色中/绿色低）
  - 显示预估完成时间和当前状态
- [ ] 添加交互功能：
  - 右键菜单（查看详情、修改优先级、取消任务）
  - 搜索框（按任务 ID、货物类型搜索）
  - 筛选器（按状态、优先级、类型筛选）
- [ ] 增强视觉效果：
  - 任务项间的分隔线
  - 鼠标悬停高亮效果
  - 选中任务的高亮显示

### 5. SimulationView（仿真视图）- 功能扩展 ⚠️

**当前功能：**

- 渲染轨道、车辆、仓库设备
- 支持鼠标选择对象
- 支持视图缩放和平移

**优化建议：**

- [ ] 添加视图辅助功能：
  - 网格显示开关
  - 坐标轴显示
  - 距离测量工具
  - 区域放大镜功能
- [ ] 增强对象可视化：
  - 车辆行驶轨迹历史显示
  - 任务路径预览（虚线显示）
  - 设备工作状态动画效果
- [ ] 改进交互体验：
  - 双击对象快速定位到检视器
  - 右键菜单快捷操作
  - 多选对象支持
