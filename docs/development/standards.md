# 编码规范

## 1. 命名规范

### 1.1 文件命名

- 头文件：使用`.hpp`扩展名
- 源文件：使用`.cpp`扩展名
- 文件名：使用大驼峰命名法（PascalCase）
- 测试文件：以`Test`结尾，如`SimulationViewTest.cpp`

### 1.2 类命名

- 使用大驼峰命名法（PascalCase）
- 类名应该是名词或名词短语
- 接口类以`I`开头，如`ISimulationInterface`

### 1.3 函数命名

- 使用小驼峰命名法（camelCase）
- 函数名应该是动词或动词短语
- 布尔函数使用`is`、`has`、`can`等前缀

### 1.4 变量命名

- 使用小驼峰命名法（camelCase）
- 成员变量以下划线结尾，如`m_count`
- 常量使用全大写，下划线分隔，如`MAX_COUNT`

## 2. 代码格式

### 2.1 缩进

- 使用 4 个空格进行缩进
- 不使用制表符（Tab）
- 保持一致的缩进风格

### 2.2 大括号

- 左大括号不换行
- 右大括号独占一行
- 空函数体使用空大括号

### 2.3 空格

- 运算符两侧加空格
- 逗号后加空格
- 分号后加空格
- 控制语句关键字后加空格

### 2.4 行长度

- 每行不超过 100 个字符
- 超长行适当换行
- 保持代码可读性

## 3. 注释规范

### 3.1 文件头注释

```cpp
/**
 * @file    SimulationView.hpp
 * @brief   仿真视图类定义
 * @author  作者名
 * @date    创建日期
 */
```

### 3.2 类注释

```cpp
/**
 * @class   SimulationView
 * @brief   负责渲染仿真场景的视图类
 */
class SimulationView {
    // ...
};
```

### 3.3 函数注释

```cpp
/**
 * @brief   更新仿真状态
 * @param   deltaTime 时间增量
 * @return  更新是否成功
 */
bool update(float deltaTime);
```

### 3.4 代码注释

- 使用`//`进行单行注释
- 复杂逻辑需要详细注释
- 避免无意义的注释

### 4.4 安全性

- 检查数组边界
- 验证输入参数
