1. **广泛搜索并筛选开源项目**
   - 记录每个项目的功能、依赖、编译方式、优缺点
2. **提取和整理所需元件**

3. **参数适配与集成测试**
   - 按需调整参数，保证仿真逻辑和 UI 逻辑可用
   - 记录所有适配和修改点
4. **持续优化与文档完善**
