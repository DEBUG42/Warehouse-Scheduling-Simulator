# 仓储仿真系统开源元件集成计划

- 集成并适配 SFML + OpenGL 的高质量 UI/仿真元件
- 保证最终代码可编译、可运行、可维护
- 记录每一步的思路、选择、试错和优化过程

## 2. 主要步骤

1. **广泛搜索并筛选开源项目**
   - 记录每个项目的功能、依赖、编译方式、优缺点
2. **提取和整理所需元件**
   - 只保留核心 UI/调度/渲染/事件代码，其他移入 `third_party/unused/`

3. **参数适配与集成测试**
   - 按需调整参数，保证仿真逻辑和 UI 逻辑可用
   - 记录所有适配和修改点
4. **持续优化与文档完善**
   - 每次试错和优化都写入本文件，便于回溯和总结

## 7. 试错与优化日志

### 2024-05-20：初始集成

- 选择 TGUI 作为主要 GUI 库，原因是其功能丰富、文档完善、社区活跃
- 采用 C++ 封装类而非直接调用原生 API，提高代码可维护性
- CMake 配置使用子目录方式（add_subdirectory）而非 find_package，确保版本一致性
- 示例程序采用百分比布局，适应不同分辨率
