# 仓库调度系统文档中心

## 文档结构

```
docs/
├── README.md              # 本文档
├── project/              # 项目文档
│   ├── structure.md      # 项目结构说明
│   ├── todo.md          # 待办事项
│   └── changelog.md     # 更新日志
│
├── development/          # 开发文档
│   ├── guide.md         # 开发指南
│   ├── standards.md     # 开发规范
│   └── build.md         # 编译说明
│
├── design/              # 设计文档
│   ├── architecture.md  # 架构设计
│   ├── gui.md          # GUI设计
│   └── api.md          # 接口设计
│
└── user/               # 使用文档
    ├── manual.md       # 用户手册
    └── faq.md         # 常见问题
```

## 文档说明

### 项目文档 (project/)

- structure.md: 详细的项目结构说明
- todo.md: 项目待办事项和计划
- changelog.md: 项目更新日志

### 开发文档 (development/)

- guide.md: 开发者指南
- standards.md: 开发规范和标准
- build.md: 编译和构建说明

### 设计文档 (design/)

- architecture.md: 系统架构设计
- gui.md: GUI 界面设计
- api.md: 接口设计文档

### 使用文档 (user/)

- manual.md: 用户使用手册
- faq.md: 常见问题解答
