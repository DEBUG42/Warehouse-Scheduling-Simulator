# 用户手册

## 系统要求

### 硬件要求

- CPU: Intel Core i5 或更高
- 内存: 8GB 或更高
- 显卡: 支持 OpenGL 3.3 或更高
- 硬盘空间: 至少 1GB 可用空间

### 软件要求

- Windows 10 或更高版本
- Visual C++ Redistributable 2019 或更高版本

## 安装说明

1. 下载最新发布版本
2. 解压到任意目录
3. 运行 `WarehouseScheduler.exe`

## 使用指南

### 主界面

主界面分为以下几个区域：

- 顶部菜单栏
- 左侧设备列表
- 中央仓库视图
- 右侧任务面板
- 底部状态栏

### 基本操作

#### 查看设备状态

1. 在左侧设备列表中选择设备
2. 设备详细信息将显示在右侧面板
3. 设备在仓库中的位置会在地图上高亮显示

#### 添加新任务

1. 点击"新建任务"按钮
2. 填写任务信息：
   - 任务名称
   - 优先级
   - 目标设备
   - 执行时间
3. 点击"确认"创建任务

#### 监控任务执行

1. 在右侧任务面板查看任务列表
2. 任务状态实时更新
3. 可以暂停/继续/取消任务

### 高级功能

#### 批量任务管理

- 支持批量导入任务
- 支持任务模板
- 支持任务优先级调整

#### 数据导出

- 支持导出任务执行报告
- 支持导出设备状态报告
- 支持导出性能分析报告

#### 系统设置

- 界面主题设置
- 显示选项设置
- 性能参数调整

## 常见问题

### 程序无法启动

1. 检查是否安装了 Visual C++ Redistributable
2. 检查系统是否满足最低要求
3. 检查杀毒软件是否阻止程序运行

### 显示异常

1. 更新显卡驱动
2. 检查显示设置
3. 尝试调整程序显示选项

### 性能问题

1. 关闭不必要的后台程序
2. 调整程序性能设置
3. 检查系统资源使用情况
