## 2. 如何构建和运行测试

### 2.1 构建测试程序

使用以下命令编译 `GUITest_Fixed.cpp` 测试程序:

```powershell
# 切换到GUI/Test目录
cd d:\CodeMaster\GitHub\C++SFML\Warehouse-sch\GUI\Test

# 使用g++编译
g++ -o GUITest_Fixed.exe GUITest_Fixed.cpp -I"G:/SFML/SFML-2.6.2/include" -DSFML_STATIC -L"G:/SFML/SFML-2.6.2/lib" -lsfml-graphics -lsfml-window -lsfml-system -std=c++17
```

> 注意: 请替换 SFML 库路径为您系统上实际的 SFML 安装路径。

或者，您可以使用 VS Code 的任务系统进行构建：

1. 打开 VS Code
2. 打开`GUITest_Fixed.cpp`文件
3. 按下 `Ctrl+Shift+B` 运行构建任务
4. 选择 "C/C++: g++.exe 生成活动文件" 任务

### 2.2 运行测试程序

编译完成后，运行生成的可执行文件:

```powershell
# 在GUI/Test目录下
.\GUITest_Fixed.exe
```

## 4. 测试程序功能说明

`GUITest_Fixed.cpp` 测试程序主要测试以下功能：

1. **轨道系统**：

   - 直道和弯道的正确渲染
   - 轨道坐标系的准确性

2. **车辆系统**：

   - 车辆渲染和动画
   - 状态显示（空载、载货、有任务）
   - 车辆在轨道上的正确定位

3. **设备/仓库系统**：

   - 上方和下方设备的正确位置
   - 设备类型显示（入库口、出库口等）
   - 设备状态显示（空闲、忙碌、故障）
   - 任务队列和进度显示

4. **交互系统**：

   - 视图控制（平移、缩放）
   - 仿真控制（暂停/继续、调整速度）

5. **UI 系统**：
   - 状态信息显示
   - 帮助提示显示
   - 性能指标（FPS）

## 5. 已知问题和解决方法

1. **字体加载问题**：

   - 症状：运行时出现"警告：无法加载字体文件"
   - 解决方法：确保 `resources/fonts/Arial.ttf` 文件存在，或修改字体路径

2. **VehicleState 和 DeviceState 定义不一致**：

   - 症状：在 MockSimulationInterface.hpp 和其他文件中对结构体的成员访问不一致
   - 解决方法：已在测试文件中统一定义，实际项目中需要保持一致的数据结构定义

3. **轨道坐标与车辆位置计算**：
   - 症状：车辆在轨道上的位置可能不准确，特别是在弯道处
   - 解决方法：测试程序使用正确的坐标系计算，实际项目中需确保使用统一的坐标系
