# 物流仓库仿真系统编译说明

## 环境要求

1. C++17 或更高版本
2. CMake 3.10 或更高版本
3. SFML 2.6
4. Visual Studio 2022（或其他支持 C++17 的编译器）

## Windows 下编译步骤

### 方法 1：使用提供的构建脚本（推荐）

1. 确保已安装 CMake，并且已添加到系统 PATH 环境变量
2. 在 PowerShell 中执行 `.\build.ps1` 脚本
3. 脚本会自动配置、编译项目并复制必要的资源文件
4. 编译完成后，可选择直接运行程序

### 方法 2：手动编译

1. 创建构建目录：`mkdir build && cd build`
2. 配置 CMake 项目：`cmake -G "Visual Studio 17 2022" -A x64 ..`
3. 编译项目：`cmake --build . --config Release`
4. 将 resources 目录复制到可执行文件所在目录

## Linux 下编译步骤

1. 确保已安装 SFML 开发库：`sudo apt-get install libsfml-dev`
2. 创建构建目录：`mkdir build && cd build`
3. 配置 CMake 项目：`cmake ..`
4. 编译项目：`cmake --build .`
5. 将 resources 目录复制到可执行文件所在目录

## 目录结构说明

- `main.cpp`：程序入口点
- `*.hpp`：头文件
- `*.cpp`：源文件
- `resources/`：资源文件（字体、图片等）
- `docs/`：项目文档
- `CMakeLists.txt`：CMake 构建配置
- `build.ps1`：Windows 构建脚本
