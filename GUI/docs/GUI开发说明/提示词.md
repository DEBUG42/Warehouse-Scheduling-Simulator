# 全文提示词

了解一下我们前面的对话信息，这个项目分为前端和后端，我们要做的是前端，不需要管后端的算法和物理约束，我们要做的是规定好与后端通信的函数或者方式，所以要求你写代码时必须用中文写全所有有利于读取了解的==注释==，

所有的文件你均可增删改查，甚至直接移除（但是我不建议你直接移除，希望你新建一个 legacy 文件夹存储暂时判断为无用的文件+代码）

并且建立两个开发文档一个用来备注你对整个项目做了哪些改动，所有的改动记录到里面，第二个是项目功能的说明文档。

==我们与后端通信主要是两个==：1.后端会告诉你有几辆小车；2.告知你每一辆小车的行驶的总路程信息，小车是逆时针转，系统的路程记录原点是左下角弯道与直道接轨处，如果小车起点不在原点视作他已经走过了一段距离；3.仿真是否倍速信息，是否停止信息；

关于重要的开发界面的信息（物流轨道的描述）在“开发界面信息.md”里
