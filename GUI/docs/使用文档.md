# 物流仓库仿真系统使用文档

## 1. 系统概述

物流仓库仿真系统是一个基于 SFML 2.6.2 和 C++ 开发的 3D GUI 仿真界面，用于模拟展示物流小车在轨道上的运动以及仓库设备状态。系统前端（GUI 部分）负责可视化显示，与后端仿真引擎通过定义好的接口进行通信。

### 1.1 主要功能

- 3D 可视化仓库轨道和设备系统
- 实时显示小车运动和状态信息
- 交互式视角控制（平移、缩放）
- 仿真控制（暂停/继续、调整仿真速度）
- 状态面板显示系统运行信息
- 设备和车辆选择查看详情

### 1.2 系统架构

系统由以下几个主要模块组成：

1. **主窗口 (MainWindow)**: 管理整个 GUI 系统，负责窗口创建、事件处理和布局管理
2. **仿真视图 (SimulationView)**: 负责绘制 3D 仿真场景，包含轨道、车辆和设备渲染器
3. **状态面板 (StatusPanel)**: 显示系统状态、车辆信息和任务列表
4. **工具栏 (Toolbar)**: 提供用户交互控制按钮
5. **仿真接口 (SimulationInterface)**: 定义与后端通信的标准接口

## 2. 系统安装与启动

### 2.1 系统要求

- Windows 10/11 或兼容的操作系统
- 支持 OpenGL 2.0 的显卡
- 最低配置：2GB RAM, 双核处理器

### 2.2 安装步骤

1. 确保已安装 SFML 2.6.2 库：

   - 下载地址: https://www.sfml-dev.org/download/sfml/2.6.2/
   - 安装指南: https://www.sfml-dev.org/tutorials/2.6/start-vc.php

2. 安装必要的编译工具：

   - 安装 MinGW 或 Visual Studio 以提供 C++编译环境

3. 获取项目源代码：
   - 从项目仓库克隆代码

### 2.3 编译和启动

使用 PowerShell 编译并运行程序：

```powershell
# 切换到项目目录
cd d:\CodeMaster\GitHub\C++SFML\Warehouse-sch\GUI

# 使用build.ps1脚本编译项目
.\build.ps1

# 运行编译后的程序
.\build\WarehouseGUI.exe
```

或者使用 CMake 构建：

```powershell
# 创建构建目录并切换到该目录
mkdir build
cd build

# 配置
cmake ..

# 构建
cmake --build .

# 运行
.\WarehouseGUI.exe
```

## 3. 用户界面指南

### 3.1 主界面布局

主界面由以下几个主要区域组成：

1. **仿真视图区域**：占据窗口左侧和中央，显示 3D 仿真场景
2. **状态面板**：位于窗口右侧，显示系统状态和详细信息
3. **工具栏**：位于窗口顶部，包含控制按钮

### 3.2 仿真视图操作

在仿真视图区域，您可以通过以下方式与场景交互：

- **平移视图**：按住鼠标左键并拖动
- **缩放视图**：使用鼠标滚轮放大/缩小
- **选择车辆/设备**：单击车辆或设备以查看详情
- **重置视图**：点击工具栏中的"重置视图"按钮

### 3.3 工具栏功能

工具栏提供以下功能按钮：

- **启动/暂停**：控制仿真运行状态
- **速度控制**：调整仿真速度（0.5x, 1x, 2x, 5x, 10x）
- **重置仿真**：将仿真状态恢复到初始状态
- **视图控制**：重置视图、显示网格等

### 3.4 状态面板功能

状态面板显示以下信息：

- **仿真状态**：当前时间、速度、是否暂停
- **车辆信息**：选中车辆的详细信息（ID、位置、速度、任务等）
- **设备信息**：选中设备的详细信息（ID、类型、状态、负载等）
- **任务列表**：当前系统中的任务状态

## 4. 理解仿真系统

### 4.1 轨道系统

轨道系统是由两段直线和两段弯道组成的环形轨道：

- **直线部分**：每段长度为 40000mm，在屏幕上由两条水平线表示
- **弯道部分**：半径为 2500mm，在屏幕上由圆弧表示
- **运行方向**：车辆在轨道上逆时针运行
- **坐标原点**：位于轨道左下角弯道中心，左下角弯道与直道接轨处为路程起点

### 4.2 设备系统

设备分布在轨道两侧：

- **上方设备（1-12 号）**：自动化库仓储区
  - 奇数：入库接口
  - 偶数：出库接口
- **下方设备（13-18 号）**：出入库作业区
  - 13-15 号：出库口
  - 16-18 号：入库口

设备状态通过不同颜色表示：

- **绿色**：入库口
- **橙色**：出库口
- **红色**：忙碌状态
- **紫色**：故障状态

### 4.3 车辆系统

车辆在轨道上运行，具有以下主要属性：

- **尺寸**：长 2000mm，宽 800mm
- **状态**：通过不同颜色表示
  - **蓝色**：空载状态
  - **橙色**：载货状态
  - **紫色**：已分配任务
- **位置**：沿轨道的位置，以左下角弯道与直道交界处为起点（0mm）

### 4.4 任务系统

任务表示车辆需要执行的操作，包括：

- **入库任务**：将货物从入库口运送到仓储区
- **出库任务**：将货物从仓储区运送到出库口
- **移动任务**：车辆在没有载货的情况下移动到指定位置

## 5. 故障排除

### 5.1 常见问题及解决方案

| 问题           | 可能原因                   | 解决方案                           |
| -------------- | -------------------------- | ---------------------------------- |
| 程序无法启动   | SFML 库缺失或路径错误      | 检查 SFML 安装和环境变量设置       |
| 显示黑屏或白屏 | 图形驱动问题               | 更新显卡驱动，检查 OpenGL 支持     |
| 车辆不移动     | 仿真暂停或后端连接问题     | 点击"启动"按钮，检查后端连接状态   |
| 界面卡顿       | 车辆数量过多或系统资源不足 | 减少车辆数量，关闭其他程序释放资源 |
| 视图异常       | 视图参数错误               | 点击"重置视图"按钮                 |

### 5.2 日志和调试

如需调试，可以：

1. 检查控制台输出，查看错误和警告信息
2. 启用详细日志：在启动程序时添加`--verbose`参数
3. 检查日志文件：位于程序目录下的`logs`文件夹

## 6. 开发和扩展

### 6.1 添加新功能

开发者可以通过以下方式扩展系统：

1. **添加新的渲染组件**：

   - 创建新的渲染器类，继承自基本渲染器
   - 在 SimulationView 中注册和使用

2. **扩展仿真接口**：

   - 在 SimulationInterface.hpp 中添加新的接口方法
   - 在 MockSimulationInterface 或实际实现中添加相应功能

3. **增强 UI 功能**：
   - 扩展 StatusPanel 或 Toolbar 类
   - 添加新的交互控件

### 6.2 与后端集成

实际项目中，需要开发一个真实的 SimulationInterface 实现来与后端通信：

1. 创建一个新类，实现 SimulationInterface 接口
2. 实现与后端的通信逻辑（可以使用 socket、共享内存等方式）
3. 在 main.cpp 中使用该实现替代 MockSimulationInterface

### 6.3 自定义配置

系统支持通过 config.json 文件进行配置：

```json
{
  "window": {
    "width": 1280,
    "height": 720,
    "title": "物流仓库仿真系统"
  },
  "simulation": {
    "defaultSpeed": 1.0,
    "trackLength": 90000,
    "curveRadius": 2500
  },
  "rendering": {
    "mmToPixel": 0.05,
    "showGrid": true,
    "showLabels": true
  }
}
```

修改此文件可以调整系统的外观和行为。
